What this agent decides

A thermometer cannot see three hours into the future, and a cooling plant needs that much notice to change mode. FortyGuard's forecast is exactly the missing input.

The agent decides, hour by hour, whether this data centre can switch its chillers off and cool with outside air — gating on temperature, humidity and contamination, the three things LBNL measured operators actually worry about. It then grades its own accuracy against reality and widens its safety margin when it is wrong.

Why — the agent's own reasoning, checkable

Generated from the same state the decision used, for whatever configuration is selected — not a script. Every claim is verified by re-running the agent: if an explanation says an hour would flip when a limit moves by 0.42 °C, the verifier moves it and checks.

No language model is used, and VRAM is not the reason. This stage reports numbers the agent already computed — the one place a model is most likely to be wrong and least excusable. Deterministic generation plus verification beats generation plus hope.

How the bound is built — the arithmetic, run in front of you

The margin is an order statistic, not a fitted parameter: sort the past errors, take the k-th smallest. So a bound has a hard arithmetic ceiling of n/(n+1) — and that one fact explains most of this project's headline failure.
