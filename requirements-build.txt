# BUILD-TIME ONLY. Everything needed to GENERATE the site report PDFs, and nothing else.
#
# ⚠ SEPARATE FROM requirements.txt, AND THE LINE MOVED ON 2026-08-31.
# This file used to say the Render image "serves pre-built reports; it never generates one". That
# stopped being true when the LIVE-run report became typeset: it is built at request time from a job
# that only exists because that run happened, so `reportlab` and `svglib` are now in the deploy list
# too, with the reasoning and the measured 33.8 MB recorded there.
#
# WHAT STAYS BUILD-ONLY IS STILL BUILD-ONLY, and that is most of the weight. `matplotlib` draws two
# charts, the plume polar and the portfolio histogram, and neither belongs in a live document: one
# describes a build-time sweep and the other a 250-site portfolio. `brotli` only exists so fontTools
# can decompress the woff2 once, and the three instanced faces it produces are committed. Same
# reasoning that keeps nvidia-warp out: a GPU solver and a font instancer are tools whose OUTPUT
# ships, not themselves.
#
# Install with:  python -m pip install -r requirements-build.txt

# The PDF document engine. Chosen over a headless-browser print because `rl_config.invariant = 1`
# fixes the document id and drops the timestamp, so the same artefacts produce byte-identical
# output. Chrome stamps a creation date into every print, which would have cost the determinism
# that audit.py and every git diff on 250 PDFs rely on. Verified: two independent builds of the
# Ashburn report hash identically.
reportlab>=4.0

# SVG to ReportLab vector graphics. Every chart, hand-written or matplotlib, goes through this one
# path, so all seven arrive as true vectors rather than raster.
# ⚠ It ignores fonts registered with reportlab and falls back to Helvetica unless you also call
# svglib.fonts.register_font. See site_report_charts.register().
svglib>=1.5

# Two charts only: the plume polar plot and the portfolio histogram. Angular axes and binning are
# where it earns the dependency; the other five charts are hand-written SVG, which costs less code
# than overriding matplotlib's defaults and inherits the document's own palette and Inter weights.
# ⚠ It has a THIRD font registry, independent of the other two. See the same register().
matplotlib>=3.8

# So fontTools can decompress demo/fonts/inter-latin.woff2. The repo ships Inter as a woff2
# VARIABLE font; ReportLab needs static TTF. tools/make_report_fonts.py instances three weights
# out of it, which is why the report and the web page render the same outlines by construction and
# no font download is needed.
brotli>=1.1
