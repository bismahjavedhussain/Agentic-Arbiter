AGENTIC-ARBITER

Free-cooling decisions, hour by hour

Cooling a data centre with outside air costs a fan. Cooling it with a chiller costs a compressor. Plants give up the cheap hours anyway, because a chiller needs hours of notice to switch and a thermometer only reports now.

FortyGuard closes that gap. It forecasts heat 2 m above the ground, the height a ground-mounted condenser actually breathes, so the plant learns what the next hours hold while it still has time to act.

This agent turns that into an hour-by-hour schedule, and every hour it releases carries a safety margin measured from its own past errors. Where the geometry defeats the physics it refuses the hour rather than guess.

Why, and how it is checked

Why: the agent's own reasoning, checkable

Generated from the same state the decision used, for whatever configuration is selected. Every claim is verified by re-running the agent.

How a claim is verified, and why no language model is used

If an explanation says an hour would flip when the limit moves by 0.42 °C, the verifier moves the limit and checks that it does.

No language model is used. This stage reports numbers the agent already computed, the one place a model is most likely to be wrong and least excusable. Deterministic generation plus verification beats generation plus hope.

The self-scoring loop
